# StackPlus Mod

StackPlus は、通常アイテムの最大スタック数を変更できる Mod です。設定値は 1 から 1,000,000,000 まで指定でき、32,767 を超える値は保存前に警告を表示します。耐久値を持つアイテムは vanilla 仕様どおりスタック不可のまま維持し、旗の模様、エンチャント本、シチュー、ポーション、バケツ、トロッコ、サドル、不死のトーテム、ボート、ヤギの角笛、レコード、ハーネスなどは例外的に設定値までスタックできます。

## 対応バージョン

Minecraft 1.21 から 1.21.11 までの Fabric 環境で動作します。

## その他

ModMenu を導入している場合、設定画面から通常アイテムの最大スタック数を変更できます。
