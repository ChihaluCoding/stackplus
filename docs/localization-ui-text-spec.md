# UI 表示テキスト多言語化仕様

## 範囲
- ModMenu 設定画面のタイトル、ボタン、ラベル、警告文を翻訳キー化する。
- アイテムツールチップの正確な個数表示を翻訳キー化する。
- `en_us` と `ja_jp` の言語ファイルを追加する。

## 制約
- インベントリ上の短縮個数表示 `K`, `M`, `B` は言語非依存のため変更しない。
- ログ出力や開発者向けコメントはゲーム内言語切替の対象外とする。
- 既存のスタック上限、描画、保存処理は変更しない。

## 受け入れ条件
- 英語設定では設定画面とツールチップに英語テキストが表示される。
- 日本語設定では設定画面とツールチップに日本語テキストが表示される。
- `gradlew.bat build` が成功する。

## 対象外
- README や仕様書の翻訳。
- Mod メタデータ表示名の動的切替。
