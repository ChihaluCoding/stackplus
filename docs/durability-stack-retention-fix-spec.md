# 耐久アイテム標準仕様への戻し

## 範囲
- 耐久値を持つアイテムは Minecraft 標準仕様どおりスタック不可にする。
- 着火石を指定対象から外し、耐久分離処理も削除する。

## 制約
- Minecraft の `ItemStack` は1スタックにつき1つの耐久値しか持てないため、耐久アイテムはスタック化しない。
- 対象外のツール、武器、防具、盾、バンドルなどは引き続き最大 1 個のままにする。
- クリエイティブスロット送信の CODEC 補正や通常アイテムのスタック上限は変更しない。

## 受け入れ条件
- 着火石などの耐久アイテムが最大 1 個になる。
- 耐久アイテム使用時に Mod 独自の分離処理が走らない。
- `gradlew.bat build` が成功する。
- 修正内容に合わせてパッチバージョンを更新する。

## 対象外
- 耐久アイテムのスタック化。
- Minecraft 1.22 以降、26.x 系の対応。
