# ModMenu スタック上限設定仕様

## 範囲
- ModMenu の設定画面から最大スタック数を変更できるようにする。
- 最大スタック数は `1` から `1,000,000,000` まで設定できる。
- 設定画面ではスライダーに加えて、横の入力欄からキーボードで数値を直接入力できる。
- 設定画面ではインベントリ上の個数表示形式を切り替えられる。
- `32,767` を超える値を保存しようとした場合、警告画面で確認する。
- 設定値は `config/stackplus.properties` に保存し、次回起動時も維持する。
- トロッコ類、サドル、ポーション類、シチュー類をスタック対象にする。

## 制約
- 耐久値を持つアイテムは Minecraft 標準仕様どおりスタック不可にする。
- 警告画面で「戻る」を選んだ場合は保存せず設定画面へ戻る。
- 警告画面で「理解して続行」を選んだ場合だけ `32,767` 超の値を保存する。
- 追加 UI 依存は ModMenu API のみとし、Cloth Config などは追加しない。
- 入力欄は数字と桁区切りカンマだけを受け付け、保存値は範囲内に丸める。
- 警告文、表示形式ボタン、保存ボタンは互いに重ならない位置に表示する。
- 設定値を下げても、既に存在する新上限超過スタックは強制分割せず、そのスタック自身の操作は現在個数まで許可する。

## 受け入れ条件
- ModMenu から StackPlus の設定画面を開ける。
- スライダーで `1,000,000,000` まで選べる。
- 入力欄へ `1000000000` または `1,000,000,000` を入力して保存できる。
- スライダー操作と入力欄の値が相互に同期する。
- 表示形式を `K/M/B` と `99+` で切り替えて保存できる。
- `32,768` 以上の保存時に指定された日本語警告が表示される。
- `32,768` 以上の値を設定しても、警告文と表示形式ボタンが重ならない。
- 設定値が通常アイテムおよび指定対象のスタック上限へ反映される。
- 設定値を下げた後でも、新上限を超える既存スタックを GUI から投げられる。
- クリエイティブスロット送信の `ItemStack.CODEC` は、ゲーム中の設定変更後でも `1,000,000,000` まで受け付ける。
- インベントリ表示は `K`, `M`, `B` の短縮表記を使い、ツールチップには正確な個数を表示する。
- `gradlew.bat build` が成功する。

## 対象外
- サーバーとの設定同期。
- 個体ごとの耐久値を同一スタック内で保持する独自仕様。
