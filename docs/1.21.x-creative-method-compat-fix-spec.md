# 1.21.x クリエイティブ判定互換修正仕様

## 範囲
- Minecraft 1.21 系全体で、スタック済み耐久アイテム使用時に `PlayerEntity.isCreative()` の中間名差分でクラッシュしないようにする。
- 耐久アイテムの分離処理は廃止し、vanilla と同じくスタック不可にする。
- クリエイティブモード専用の分岐に依存しない。

## 制約
- 1.21 初期版向けビルドを維持し、1.21 系途中で変更されたメソッドへ直接依存しない。
- スタック上限、対象アイテム判定、CODEC 補正の仕様は変更しない。
- 有料 API、外部有料サーバー、秘密情報は使用しない。

## 受け入れ条件
- Minecraft 1.21.10 で `net.minecraft.class_1657.method_7337()` の `NoSuchMethodError` が発生しない。
- 耐久分離 Mixin を使わないため、`PlayerEntity.isCreative()` の中間名差分へ依存しない。
- Gradle ビルドが成功する。
- 修正内容に合わせてパッチバージョンを更新する。

## 対象外
- Minecraft 1.22 以降、26.x 系の対応。
- Minecraft 1.22 以降、26.x 系の対応。
