# StackPlus 26.x バージョン別専用プロジェクト仕様

## 範囲
- `26.x` フォルダ内に Minecraft 26.x 系のバージョン別専用プロジェクトを配置する。
- 対象は `26.1`、`26.1.1`、`26.1.2`、`26.2`、`26.3-snapshot` とする。
- 各フォルダは `build.gradle`、`gradle.properties`、`settings.gradle`、`gradle/`、`src/`、`gradlew`、`gradlew.bat` を持ち、単独でビルドできる。
- 各フォルダの `README.md` に対象 Minecraft バージョン、ビルド方法、生成 jar 名を書く。

## 制約
- 各プロジェクトの `minecraft_version` と `archives_base_name` は対象バージョン専用にする。
- `fabric.mod.json` の `minecraft` 依存条件も対象バージョン専用にする。
- ModMenu 未導入時は既定値の 1000 個スタック、1K 表示として動作する。
- ModMenu 導入時は設定画面から最大スタック数を 1 から 1,000,000,000 まで変更できる。
- ツールチップには 2 個以上のスタックで正確な個数を表示する。
- API キー、外部有料サービス、外部サーバーは使用しない。

## 受け入れ条件
- `26.x/26.1` が Minecraft 26.1 専用プロジェクトとしてビルド成功する。
- `26.x/26.1.1` が Minecraft 26.1.1 専用プロジェクトとしてビルド成功する。
- `26.x/26.1.2` が Minecraft 26.1.2 専用プロジェクトとしてビルド成功する。
- `26.x/26.2` が Minecraft 26.2 専用プロジェクトとしてビルド成功する。
- `26.x/26.3-snapshot` が Minecraft 26.3 snapshot 2 専用プロジェクトとしてビルド成功する。

## 対象外
- 1.21.x プロジェクトの変更。
- 26.x 系を単一 jar で同時対応すること。
