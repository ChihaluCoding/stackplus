# StackPlus 26.1.x 専用ビルド仕様

## 範囲
- 26.2 用プロジェクトとは別に、26.1.x 専用フォルダでビルドできる構成を作る。
- Minecraft 26.1.x 系の対象は 26.1 から 26.1.2 までとする。
- 26.2 版 2.0.0 と同じ StackPlus 仕様を維持する。
- ModMenu 未導入時は既定値の 1000 個スタック、1K 表示として動作する。
- ModMenu 導入時は設定画面から最大スタック数を 1 から 1,000,000,000 まで変更できる。
- チェスト保存、ネットワーク受信、スロット投入、ツールチップ正確個数表示に対応する。

## 制約
- 元の 26.2 プロジェクトは変更しない。
- 専用フォルダ内だけで Gradle 設定を 26.1 用にし、依存条件は 26.1 以上 26.2 未満へ調整する。
- API キー、外部有料サービス、外部サーバーは使用しない。
- `.gradle`、`build`、`run` などの生成物フォルダはコピー対象外にする。

## 受け入れ条件
- `stackplus-26.1.x Fabric` フォルダが存在する。
- 専用フォルダ内の `gradle.properties` が Minecraft 26.1 と Fabric API 26.1 を参照する。
- 専用フォルダ内の `fabric.mod.json` が Minecraft 26.1 以上 26.2 未満を要求する。
- 専用フォルダ内の `mod_version` が 2.0.0 である。
- ModMenu 導入時に 1,000,000,000 まで設定でき、未導入時は 1000 個上限で動作する。
- 専用フォルダ内で `./gradlew.bat build` が成功する。

## 対象外
- 26.1.1 個別の起動検証。
- 26.2 版と 26.1.x 版の単一 jar 統合。
