# スタック数表示とツールチップ仕様

## 範囲
- インベントリ上の個数表示を `K`, `M`, `B` の言語非依存な短縮表記にする。
- ModMenu 設定から表示形式を `K/M/B` 表記と `99+` 表記で切り替えられるようにする。
- 代表値は `1K = 1,000`, `10K = 10,000`, `100K = 100,000`, `1M = 1,000,000`, `10M = 10,000,000`, `100M = 100,000,000`, `1B = 1,000,000,000` とする。
- アイテムツールチップに正確な個数をカンマ区切りで表示する。

## 制約
- 個数が `1000` 未満の場合は vanilla と同じ数値表示を維持する。
- スロット内の個数ラベル描画は Minecraft 標準の描画処理に委ね、短縮済み文字列だけを渡す。
- `1000` 以上は基本的に `K`, `M`, `B` の言語非依存な単位で表示する。
- `99+` 表記では `100` 個以上をすべて `99+` と表示する。
- `100K` から `999K` のように単位付きで4文字になるK範囲でも、数値だけに見えないよう `K` を維持する。
- `100M` 以上のM範囲は、数値の意味を保つため単位を省略しない。
- 1.21 系途中の `DrawContext` メソッド差分やフィールド名差分に依存せず、1.21.7 などでも描画時にクラッシュしない。
- 短縮表示は切り捨てとし、実数より大きい単位量に見える繰り上げはしない。
- ツールチップ追記は 2 個以上のスタックに表示する。

## 受け入れ条件
- `1000` が `1K`、`100000` が `100K`、`1000000` が `1M`、`100000000` が `100M`、`1000000000` が `1B` と表示される。
- `99+` 表記へ切り替えると、`100` 個以上が `99+` と表示される。
- `999500` は `999`、`99999955` は `99M` のように、実数より大きい値へ繰り上げない。
- `781K`, `999K`, `100M` のような4文字表示でも単位を消さない。
- `1K`, `1M`, `99M` のような短い表示が空表示にならない。
- 1.21.7 で起動しても `DrawContext` の `MatrixStack` フィールド名差分による Mixin 適用エラーが発生しない。
- 1.21.7 でインベントリ画面を描画しても `DrawContext.drawText` のメソッド名差分による `NoSuchMethodError` が発生しない。
- 1.21.7 で1000個以上のスタック数が空表示にならない。
- 2 個以上のアイテムツールチップに `個数: 2` や `個数: 1,000` のような正確な個数が表示される。
- 設定上限を `1000` 以下へ下げた後でも、その上限を超える既存スタックのツールチップに正確な個数が表示される。
- `gradlew.bat build` が成功する。

## 対象外
- アイテム名や説明文の置換。
- 1,000,000,000 を超える設定上限の追加。
