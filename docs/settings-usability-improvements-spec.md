# 設定画面と設定ファイル改善仕様

## 範囲
- 設定を下げた時の既存スタックの扱いを設定画面で説明する。
- 表示形式 `K/M/B` と `99+` の意味を設定画面で説明する。
- 設定ファイルが壊れている場合は `.broken` ファイルへ退避して既定値で復旧する。
- よく使う最大スタック数をプリセットボタンで選べるようにする。
- `32,767`、`1,000,000`、`100,000,000` 以上で警告文を段階的に変える。

## 制約
- 追加 UI 依存は入れない。
- 既存スタックは設定値を下げても自動分割・削除しない。
- 既存の保存ファイル形式は維持し、追加キーがない古い設定も読み込めるようにする。

## 受け入れ条件
- 設定画面に既存スタック維持の説明が表示される。
- 表示形式ボタンの下に現在形式の説明が表示される。
- 壊れた `stackplus.properties` は `.broken` 付きファイルへ退避される。
- `64`、`999`、`1K`、`10K`、`1M`、`1B` のプリセットを押して値を反映できる。
- 危険値の警告文が値の大きさに応じて切り替わる。
- 警告画面は長文を避け、要点だけを短い行で表示する。
- `gradlew.bat build` が成功する。
