# StackPlus 26.x 版 1.21.x 仕様反映

## 範囲
- `1.21.x` ディレクトリの StackPlus 仕様を、ルートの Minecraft 26.2 向け実装へ反映する。
- 最大スタック数を `1` から `1,000,000,000` まで設定可能にする。
- ModMenu から設定画面を開き、スライダー、直接入力、プリセット、表示形式切り替えを利用できるようにする。
- ModMenu が入っていない場合は設定画面を使えないため、既定値の `1,000` を最大スタック数として動作する。
- 設定値と表示形式を `config/stackplus.properties` に保存する。
- インベントリ表示を `K/M/B` または `99+` 形式で切り替え、正確な個数をツールチップへ表示する。
- トロッコ類、サドル、ポーション類、シチュー類など `1.21.x` と同じ対象を通常アイテム同様にスタック可能にする。

## 制約
- ルート実装の Minecraft 26.2 / Java 25 / Fabric 26.2 対応を維持する。
- 26.x 用に追加済みの `ItemInstance`、`StackPlusCodecs`、パケット/Codec 対応は維持する。
- 耐久値を持つアイテムは Minecraft 標準仕様どおりスタック不可にする。
- `32,767` を超える設定値を保存する場合は確認画面を挟む。
- 追加 UI 依存は ModMenu API のみにする。
- API キー、有料 API、有料サーバーは使用しない。

## 受け入れ条件
- ルートの `gradlew.bat build` が成功する。
- `fabric.mod.json` が ModMenu entrypoint と任意依存を持つ。
- ModMenu 設定画面で `1,000,000,000` まで選択/入力/保存できる。
- ModMenu 未導入時は追加設定なしで最大スタック数 `1,000` として動作する。
- `config/stackplus.properties` から設定値と表示形式を読み書きできる。
- スタック上限を下げても、既存の新上限超過スタックは現在個数まで操作できる。
- クリエイティブ送信や保存用 Codec が `1,000,000,000` までの個数を受け付ける。
- 言語ファイルに設定画面、警告、ツールチップ文言が含まれる。

## 対象外
- サーバーとの設定同期。
- 個体ごとの耐久値を同一スタック内で保持する独自仕様。
- Minecraft 26.1.x 専用ディレクトリの変更。
