# StackPlus for Minecraft 26.3 Snapshot

Minecraft 26.3 snapshot 用の jar はまだ作成していません。

## 理由
- このリポジトリには 26.3 snapshot 向けのビルド設定と検証済み依存関係がありません。
- 26.1.x 用または 26.2 用 jar を 26.3 snapshot に入れると、Fabric Loader の互換性チェックまたは実行時 API 差分で失敗する可能性があります。

## 対応状況
- 26.3 snapshot へ移植する場合は、別途 26.3 snapshot 用の Gradle 設定、Fabric API、互換性検証が必要です。
