## What is StackPlus?
StackPlus increases the maximum stack size for normal items to **1K** in both **Minecraft 1.21.x** and **Minecraft 26.x**.

If ModMenu is installed, you can change the stack limit from **1** up to **1,000,000,000**. Without ModMenu, StackPlus uses the default **1K** limit. Items with durability keep Minecraft's vanilla behavior and remain unstackable, while selected normally single-stack items such as potions, stews, buckets, minecarts, saddles, boats, goat horns, music discs, and harnesses can stack up to the active limit.

---

## Features
- **Configurable stack limit:**  
  With ModMenu installed, set the maximum stack size anywhere from 1 to 1,000,000,000.
- **1K default without ModMenu:**  
  If ModMenu is not installed, the maximum stack size stays at 1K.
- **Same behavior across versions:**  
  The 1.21.x and 26.x builds now use the same StackPlus specification.
- **ModMenu support:**  
  If ModMenu is installed, you can change the stack limit from the in-game config screen.
- **Safer large values:**  
  Values above 32,767 show a warning before saving.
- **Vanilla durability behavior:**  
  Damageable items such as tools, weapons, armor, shields, and similar equipment remain unstackable.
- **Better stack count display:**  
  Large stack counts can be shown as K/M/B or 99+, with the exact count available in the tooltip.
