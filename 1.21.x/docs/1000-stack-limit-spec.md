# StackPlus 可変スタック対応仕様

## 範囲
- 通常アイテムの最大スタック数を ModMenu 設定値に変更する。
- スロット投入時の上限判定も設定値に合わせる。
- チェストなどのコンテナ保存時の上限判定も設定値に合わせる。
- チェストなどのコンテナをワールド保存・再読み込みしても設定値までのスタックを維持する。
- クライアントのアイテム個数表示は 1000 個以上を K 表記にする。
- クリエイティブのスロット設定パケットでも設定値の ItemStack を受け付ける。
- ベッドは既存方針どおり通常アイテムと同じ上限にする。
- 装備、ツール、武器、盾、バンドル、シュルカーボックスなど、元の最大スタック数が 1 のアイテムはスタック不可のまま維持する。
- README、Mod メタデータ、初期化ログ、バージョンを可変上限仕様に合わせる。

## 制約
- 既存の mod ID、パッケージ構造、Mixin 構成は変更しない。
- ModMenu 設定画面以外のコマンドなどは追加しない。
- API キー、外部有料サービス、外部サーバーは使用しない。
- 既存の未コミット変更は維持する。

## 受け入れ条件
- `StackLimitConfig` が 1 から 1,000,000,000 の設定値を扱える。
- 通常アイテムとベッドの最大スタック数が設定値になる。
- 通常アイテムをスロットに置く時も 99 個で止まらず設定値まで入る。
- 通常アイテムをチェストなどのコンテナへ入れても 99 個に丸められない。
- 通常アイテムをチェストなどのコンテナへ入れてワールドに入り直しても、アイテムが消えず設定値まで維持される。
- 1000 個のスタックは GUI 上で `1K` と表示される。
- 設定値の通常アイテムをスロットに置いても `set_creative_mode_slot` の decode 例外で切断されない。
- 元の最大スタック数が 1 のアイテムは 1 のままになる。
- `./gradlew.bat build` が成功する。

## 対象外
- サーバー専用 mod 化。
- アイテム別の上限設定。
- UI 表示形式の独自描画。
