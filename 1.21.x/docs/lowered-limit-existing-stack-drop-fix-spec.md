# 設定上限引き下げ後の既存スタック操作修正仕様

## 範囲
- 最大スタック数を下げた後でも、既に新上限を超えて存在しているスタックを GUI から投げられるようにする。
- 既存スタックの移動、分割、ドロップ処理で現在個数が新上限を超えていても不正扱いにならないようにする。
- 設定上限を `1000` 以下へ下げても、新上限を超える既存スタックのツールチップに正確な個数を表示する。

## 制約
- 設定値を下げた時点で既存スタックを強制分割・削除しない。
- 新しく積み増せる上限は現在の設定値を維持する。
- 耐久値を持つアイテムは引き続き Minecraft 標準仕様どおりスタック不可にする。

## 受け入れ条件
- 1,000,000,000 個などの既存スタックがある状態で設定値を下げても、GUI から投げたアイテムが消えずにドロップする。
- 既存スタック自身の `getMaxCount` は現在個数を下回らない。
- 既存スタックの個数が現在の設定上限を超える場合、`1000` 未満でもツールチップに `個数: %s` を表示する。
- `gradlew.bat build` が成功する。
