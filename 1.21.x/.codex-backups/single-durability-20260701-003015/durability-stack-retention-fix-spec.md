# 耐久アイテムのスタック維持修正仕様

## 範囲
- スタック可能にした耐久アイテムを使用しても、使用後に別スタックへ分離しないようにする。
- 使用時に分離元と分離先の両方で耐久が減る状態を防ぐ。
- 着火石を含む指定対象アイテムの最大スタック数 1000 は維持する。

## 制約
- 耐久値を個体ごとに別々には保持しない。Minecraft の `ItemStack` として1つの耐久値を共有する。
- 対象外のツール、武器、防具、盾、バンドルなどは引き続き最大 1 個のままにする。
- クリエイティブスロット送信の CODEC 補正や通常アイテムのスタック上限は変更しない。

## 受け入れ条件
- 着火石などの指定耐久アイテムをスタック状態で使っても、使用後に1個だけ別スタックへ分離されない。
- 耐久減少処理を Mod 側で二重に呼ばない。
- `gradlew.bat build` が成功する。
- 修正内容に合わせてパッチバージョンを更新する。

## 対象外
- 個体ごとの耐久値を保持したまま同一スタックに混在させる独自データ構造の追加。
- Minecraft 1.22 以降、26.x 系の対応。
