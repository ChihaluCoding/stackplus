# スタック数表示とツールチップ仕様

## 範囲
- インベントリ上の個数表示を `K`, `M`, `B` の短縮表記にする。
- 代表値は `1K = 1,000`, `10K = 10,000`, `100K = 100,000`, `1M = 1,000,000`, `10M = 10,000,000`, `100M = 100,000,000`, `1B = 1,000,000,000` とする。
- アイテムツールチップに正確な個数をカンマ区切りで表示する。

## 制約
- 個数が `1000` 未満の場合は vanilla と同じ数値表示を維持する。
- 端数がある短縮表示は小数 1 桁までに丸める。
- ツールチップ追記は `1000` 個以上のスタックに限定する。

## 受け入れ条件
- `1000` が `1K`、`1000000` が `1M`、`100000000` が `100M` と表示される。
- `1000` 個以上のアイテムツールチップに `個数: 1,000` のような正確な個数が表示される。
- `gradlew.bat build` が成功する。

## 対象外
- アイテム名や説明文の置換。
- 100,000,000 を超える設定上限の追加。
