# StackPlus

Minecraftの通常のスタック上限を拡張し、**1つのスタックに最大1,000,000,000個**のアイテムをまとめられます。

大きな個数を見やすく表示できるほか、アイテムごとのルールやゲーム内設定画面も利用できます。

## 主な機能

| 機能 | 詳細 |
| --- | --- |
| 全体のスタック上限 | **1**から**1,000,000,000**までの値を設定できます。 |
| クイックプリセット | よく使う上限へすぐに切り替えたり、独自のプリセットを保存したりできます。 |
| アイテム別ルール | アイテムごとにスタックの許可・禁止と上限を設定できます。 |
| 省略表示 | 大きな個数を**K**、**M**、**B**、または**99+**で表示できます。 |
| ツールチップ表示 | 省略された個数と正確な個数をツールチップで確認できます。 |
| ホットバー上の合計所持数 | 選択中のアイテムがインベントリ内に合計いくつあるかをホットバーの上に表示できます。 |
| 表示のカスタマイズ | アイテム数の表示位置、表示方法、文字色を変更できます。 |
| 更新通知 | 設定画面から更新通知の有効・無効を切り替えられます。 |

ツール、武器、防具、盾など耐久値を持つ装備は、バニラと同様に初期状態ではスタックできません。

## 設定方法

スナップショット版を除き、[Mod Menu](https://modrinth.com/mod/modmenu)の導入が必須です。正確な上限の入力、プリセットの選択、個数表示の調整、アイテム別設定など、すべての設定をゲーム内から変更できます。

スナップショット版はMod Menuなしでも起動できます。その場合、最大スタック数は初期値の**1,000**になります。
