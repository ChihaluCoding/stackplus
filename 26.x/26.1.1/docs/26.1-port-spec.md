# StackPlus 26.1.x 対応仕様

## 範囲
- Minecraft 26.1.x 系として 26.1.2 を対象にビルドできるようにする。
- Fabric 26.1 系の公式名環境に合わせて Gradle 設定と Java ソースを更新する。
- スタック上限変更は、元の最大スタック数が 2 以上のアイテムだけに適用する。
- 装備、ツール、武器、盾、バンドル、シュルカーボックスなど vanilla で 1 個上限のアイテムはスタック不可のまま維持する。

## 制約
- Fabric の 26.1 移行仕様に従い、Yarn mappings には依存しない。
- Java 25 以上を前提にする。
- API キーや外部有料サービスは使用しない。
- 既存の mod ID とパッケージ構造は維持する。

## 受け入れ条件
- `./gradlew.bat build` が成功する。
- `fabric.mod.json` の依存条件が Minecraft 26.1.2 と Java 25 を要求する。
- 通常アイテムのスタック上限は 99 になる。
- 装備、ツール、武器、盾、バンドル、シュルカーボックスを含む、元の最大スタック数が 1 のアイテムは 1 のままになる。

## 対象外
- 設定画面やゲーム内コマンドによる上限変更。
- サーバー専用 mod 化。
- Minecraft 26.2 以降への対応。
