# StackPlus 26.x バージョン別配布仕様

## 範囲
- `26.x` フォルダ内に Minecraft 26.x 系のバージョン別配布物を配置する。
- `26.1`、`26.1.1`、`26.1.2` には 26.1.x 専用 jar を配置する。
- `26.2` には 26.2 専用 jar を配置する。
- 各フォルダに利用対象と ModMenu 有無の挙動を説明する `README.md` を配置する。

## 制約
- Minecraft 26.1.x 用 jar は `minecraft >=26.1 <26.2` の依存条件を維持する。
- Minecraft 26.2 用 jar は `minecraft >=26.2 <26.3` の依存条件を維持する。
- Minecraft 26.3 snapshot は対応ビルドが無いため、jar を配置しない。
- 既存の 1.21.x プロジェクトは変更しない。
- API キー、外部有料サービス、外部サーバーは使用しない。

## 受け入れ条件
- `26.x/26.1`、`26.x/26.1.1`、`26.x/26.1.2` に 26.1.x 用 jar がある。
- `26.x/26.2` に 26.2 用 jar がある。
- `26.x/26.3-snapshot` には未対応であることを示す README がある。
- 26.1.x 用と 26.2 用の Gradle ビルドが成功する。

## 対象外
- 26.3 snapshot 用の新規ポート。
- 単一 jar で 26.1 から 26.2 までを同時対応すること。
